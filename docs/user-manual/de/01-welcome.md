# Kapitel 1: Willkommen bei OmniPanel-go

## Was ist OmniPanel-go?

OmniPanel-go verwandelt jedes Touch-Gerät in deinem Heimnetzwerk — wie ein Tablet, Handy oder altes Laptop — in ein individuelles Bedienfeld für deine Spiele. Stell es dir so vor, als würdest du dir dein eigenes Cockpit-Dashboard oder Missionskontrollzentrum bauen, direkt auf deinem iPad oder Android-Tablet.

Stell dir vor, du spielst eine Weltraum-Simulation und hast einen zweiten Bildschirm mit Buttons für das Fahrwerk, Schiebereglern für den Schub und einem Touchpad für die Kamerasteuerung. Genau das macht OmniPanel-go.

## Was macht es besonders?

- **Keine Konten nötig** — Keine Registrierung, keine Passwörter, keine Cloud-Dienste
- **Funktioniert offline** — Alles läuft auf deinem eigenen Computer
- **Komplett privat** — Alle Daten bleiben in deinem lokalen Netzwerk
- **Kostenlos und Open-Source** — Keine versteckten Kosten oder Premium-Funktionen
- **Eine Datei zum Starten** — Kein komplizierter Installationsprozess

## Wie funktioniert es?

Hier ist die einfache Version:

1. Du startest OmniPanel-go auf deinem Gaming-PC
2. Du entwirfst Bedienpanels mit einem visuellen Editor (Drag-and-Drop)
3. Du öffnest das Panel auf deinem Tablet, indem du eine Webadresse aufrufst
4. Wenn du auf deinem Tablet Buttons drückst oder Slider verschiebst, sendet OmniPanel-go diese Eingaben an dein Spiel, als kämen sie von einem echten Gamecontroller

Dein Spiel sieht OmniPanel-go als ganz normalen Joystick oder Maus. Keine speziellen Spiel-Mods oder Plugins nötig.

## Was brauchst du?

### Erforderlich

- **Ein Gaming-PC** mit Windows oder Linux (macOS wird für Spieleingaben nicht unterstützt)
- **Ein Touch-Gerät** — jedes Tablet, Handy oder Laptop mit Touchscreen und Webbrowser
- **Beide Geräte im selben WiFi-Netzwerk** — sie müssen mit demselben Router verbunden sein

### Optional

- **Mehrere Touch-Geräte** — du kannst verschiedene Panels auf verschiedenen Geräten haben
- **Ein zweiter Monitor** — praktisch, um das OmniPanel-go-Dashboard während des Spielens sichtbar zu halten

## Was kannst du bauen?

Hier sind einige Beispiele:

- **Flugsimulator-Cockpit** — Schubregler, Klappen-Buttons, Fahrwerk-Schalter
- **Rennspiel-Dashboard** — Gangwahl, Boost-Button, Bremsbalance-Regler
- **Weltraumspiel-Bedienfeld** — Waffengruppen, Schild-Management, Navigation
- **Allgemeine Gaming-Hilfsmittel** — Lautstärkeregler, Screenshot-Button, App-Starter
