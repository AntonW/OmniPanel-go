## Schnellstart

1. **Starte OmniPanel-go** auf deinem Gaming-PC
2. **Öffne deinen Browser** und gehe zu `http://dein-pc-ip:3000`
3. **Erstelle ein Panel** mit dem visuellen Editor
4. **Öffne das Panel** auf deinem Tablet oder Handy
5. **Spiele dein Spiel** mit einem individuellen Bedienfeld

---

> **Hinweis:** Dieses Handbuch ist für Gamer ohne technisches Fachwissen geschrieben. Wenn du einen Webbrowser bedienen und Dateien per Drag-and-Drop verschieben kannst, kannst du OmniPanel-go nutzen.
